Vladik MATEMATIK v2.0
Автономный математический движок с графическим интерфейсом.
Работает полностью офлайн, без нейросетей — только SymPy, NumPy, SciPy, Matplotlib.

Уравнения — алгебраические, системы, неравенства, дифференциальные (ODE)
Комплексные решения — поддержка x² + 1 = 0 → x = ±i
Матан — производные, интегралы (определённые и нет), пределы, ряды Тейлора, упрощение/раскрытие/факторизация
Оптимизация — поиск min/max функции на отрезке
Матрицы — определитель, ранг, обратная, собственные значения, A+B, A·B
Графики — 2D, 3D с вращением, полярные, параметрические, неявные
Экспорт — PNG/PDF/SVG в 300 dpi
История решений — сохраняется между запусками
Тёмная / светлая тема
Верификация ответов — автоматическая проверка подстановкой

Установка:
pip install sympy numpy matplotlib scipy

Запуск:
python vladik_matematika.py

Требования:
Python 3.8+
SymPy, NumPy, Matplotlib
SciPy (опционально — для оптимизации)
ОС: Windows / Linux / macOS

Лицензия:
Свободное использование в образовательных целях.
